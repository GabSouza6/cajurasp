# Instruções para agentes

- Leia o README e estas instruções antes de alterar o projeto.
- Respeite a stack e a estrutura existentes: React, Vite e Tailwind em `frontend/`; Express e TypeScript em `backend/`; npm workspaces.
- Trabalhe uma issue por vez, diretamente na `main`, sem antecipar etapas.
- Preserve alterações locais e a pasta `design/`.
- Nunca publique segredos, credenciais, tokens ou conteúdo de arquivos `.env`.
- Adicione testes relevantes junto das funcionalidades.
- Antes de concluir, execute as verificações aplicáveis: `npm run lint`, `npm run typecheck`, `npm run test` e `npm run build`, ou `npm run check`.
- Não execute operações de escrita no Git, como `add`, `commit`, `pull`, `push`, `merge` ou criação de branches, sem solicitação explícita.
